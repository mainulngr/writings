# পরিভাষা — craft vocabulary, English ↔ Bangla

The lane's shared terms. Scaffolds and course notes use the Bangla word
primary (English in parens on first use). Grows as new terms appear —
never rename a row after it's in use; add a note instead.

| English | বাংলা | মানে কী |
|---|---|---|
| blueprint | **নকশা** | লেখার আগের পরিকল্পনা — কোন ধাপ কোথায়, কেন |
| atom (story atom) | **গল্পের পরমাণু** | চরিত্র + চাওয়া + বাধা + মোড় — গল্প চলার মূল ইঞ্জিন |
| beat | **ধাপ** | যে একটা ঘটনা বা মুহূর্তে গল্পটা এক ধাপ এগোয় |
| guardrails | **রক্ষাকড়া** | যে নিয়মগুলোর বাইরে গেলে এই গল্পটা ভেঙে যায় |
| logline | **এক লাইনের গল্প** | পুরো গল্প এক বাক্যে |
| shape | **গঠন** | গল্পের আকার — মোড়ের-মুহূর্ত, উন্মোচন, চক্র, চিত্র-ছায়া |
| POV | **দৃষ্টিকোণ** | গল্পটা কার চোখে দেখা হচ্ছে |
| tense | **কাল** | বর্তমান না অতীত |
| plant | **বীজ** | শুরুতে চুপচাপ রাখা জিনিস, যা শেষে কাজ করে |
| callback | **বীজ ফেরা** | সেই জিনিসের শেষে ওজন নিয়ে ফিরে আসা (ডিভাইস ১৮) |
| turn | **মোড়** | যে মুহূর্তের পর চরিত্র আগের মতো থাকে না |
| counter-want | **পাল্টা চাওয়া** | আরেক চরিত্রের চাওয়া, যা বাধা তৈরি করে |
| friction | **বাধা** | চাওয়া আর পাল্টা চাওয়ার সংঘর্ষ |
| scene vs summary | **দৃশ্য বনাম সারমর্ম** | ঘটে-যাওয়া মুহূর্ত বনাম বলে-দেওয়া ভাবনা — মডিউল ১-এর মূল পার্থক্য |
| landing | **নামা** | গল্প শেষ হওয়ার ভঙ্গি — আস্তে নামা, আচমকা পড়া না |
| flashback | **পেছনে-ফেরা** | আগের ঘটনায় ফিরে যাওয়া |
| draft | **খসড়া** | প্রথম লেখা — ঠিক করার জন্য, প্রমাণের জন্য না |
| held ambiguity | **দুই সত্য ধরে রাখা** | দুই পক্ষের সত্য একসাথে রেখে সমাধান না করা (ডিভাইস ১৭) |
