# short-fiction — study subject

Learning lane for short-story craft: structural technique + idea hunting,
aimed at Bangla-first fiction including attention-span micro-forms for
social. Change record: `_journal/changes/story-learning-lane/`.

## Contents

- `niche-scan.md` — the landscape: platforms, forms, what works, what's
  dead. Evidence-based, grows as recon continues.
- `course.md` — the curriculum: modules, exercises, artifacts.
- Teardown reports (one per app studied) — files land here, extracted
  trees stay in `data/teardowns/` on /mega.

## The corpus

Reference material lives outside the repo: `data/` →
`/mega/mountain/writings/` (own git inside).

- `corpora/` — story collections for study (public-domain Bangla classics,
  flash anthologies, platform samples). Educational reference only.
- `teardowns/` — extracted APK trees (local, unversioned).
- `derived/` — hand-built catalogs: annotated exemplars, form taxonomy —
  versioned in the mega repo.
