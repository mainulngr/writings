# Exemplars — study files for modern Bangla stories

One file per story: provenance, structure map, devices, honest weaknesses,
study questions, re-siting seeds. The *full text* never lives in this
tracked repo when the work is copyrighted — it goes to
`data/exemplars/modern-bangla/` (local-only data repo, no remote), and this
folder carries only short quotes plus the dissection.

Rule: quote for analysis, never reproduce whole. If a story is public
domain, it belongs in `data/corpora/` instead.
