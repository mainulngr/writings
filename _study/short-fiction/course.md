# Short-fiction course — structural craft + idea hunting

Calibrated to `voice.md`: Bangla-first, gentle, collective subjects, soft
landings. Goal: structure he can *reuse*, not rules to memorize. Every
module ends in an artifact in `stories/` — the course produces corpus.

Progress: module 0 ☐ · 1 ☐ · 2 ☐ · 3 ☐ · 4 ☐ · 5 ☐ · 6 ☐ · 7 ☐

## How each module works

**Read** (corpus exemplars) → **Dissect** (name the technique out loud —
write the annotation) → **Write** (the exercise) → `voice-check` →
artifact lands in `stories/<band>/`. One module = as long as it takes;
no deadlines.

## Module 0 — Baseline

- Write one story *now*, before learning anything — the reference point
  growth is measured against. Any subject, any length.
- Artifact: `stories/adult/_baseline.md` (underscore = course file).

## Module 1 — The atom

- Concept: a story = character + want + friction + turn. Scene vs summary;
  compression lives in scene.
- Dissect: take one existing `social/` post that *almost* is a story —
  name what's missing.
- Exercise: rewrite that post AS a scene (same subject, story shape).
- Gate: can name want/friction/turn in any story read.

## Module 2 — Compression ladder: micro-forms

- Forms: six-word → dribble (~50) → drabble (exactly 100) → micro (<300).
- Craft: the unsaid does the work; title carries weight; every sentence
  does two jobs.
- Exercise: one drabble per day for a week (Bangla). One lands in
  `stories/`; the week teaches more than the piece.
- Gate: a complete arc in ≤100 words that a reader feels, not parses.

## Module 3 — Structure shapes

- The four shapes that cover most short fiction: moment-of-change,
  reveal, loop, vignette-that-implies.
- Endings: open vs closed; calibrate the gentle landing vs the cheap
  twist — the turn should feel inevitable-quiet, not gotcha.
- Dissect: `stories/adult/brishtir_opokkha.md` — name its shape. (Vignette-
  implies / loop — the rain arrives, the radio hums, nothing "happens".)
- Exercise: write the same seed twice in two different shapes; compare.
- Gate: choose a shape *before* drafting, deliberately.

## Module 4 — POV, tense, dialogue

- His habit: তারা/মানুষ collective distance. When does first-person earn
  its place (Human Version rules already exist — same logic)?
- Present tense for intimacy; past for reflection.
- Bangla dialogue texture: contractions, code-mixing limits, the
  অল্পবিত্তা of real speech.
- Exercise: two versions of one scene — তারা vs আমি — and feel the
  distance change.

## Module 5 — Idea hunting (the system, not the talent)

- Sources ranked: observed scene > overheard line > memory > premise
  engine (what-if / inversion / small-thing-standing-for-big-thing) >
  seasonal hook > generated.
- Practice: 3 seeds/week into `_starter/idea_backlog.md` — raw, one line,
  no judgment. `social-pipeline` already knows how to consume them.
- Mining his own corpus: every `social/` post is a compressed story seed —
  pick one, expand.
- Gate: backlog grows faster than it drains.

## Module 6 — Attention-span mechanics

- Line-1 hooks that are *honest* — tension or texture, never clickbait.
- Paragraph rhythm on mobile: short beats, breath points, the Commaful
  page-turn instinct applied to a text post.
- The styled-bg variant IS a micro-fiction form — treat it as one
  (1–4 lines, self-contained, felt).
- Exercise: one micro-story built FOR the styled background, not adapted.

## Module 7 — Serialization & capstone

- Returning character or world = follow-worthy serial (Commaful's parts
  mechanic). Design one recurring figure who can carry a series.
- Capstone: a linked 5-part micro-collection — drafted, voice-checked,
  slotted for the lanes.
- After module 7: distill earned children's-register observations into
  `voice.md` (closes that open question if the pieces were children's).

## The adaptation principle

We import the *apparatus* — premise, structure, turn, constraint — never
the content. `device-catalog.md` is the spine, and it runs three rings:
Bangla classics (structure in the home register), world literature via
translation (devices Bangla lacks), modern highly-rated Bangla (the
contemporary register — dissected for *why they hit*). Each module picks
1–2 devices, reads the exemplar, and the exercise is the same setup
retold in his own culture and language.
