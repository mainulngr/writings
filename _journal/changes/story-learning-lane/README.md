# story learning lane

## Why

Mainul wants a learning lane for short stories — including
attention-span-ready micro-fiction for social media. Goal: structural
story craft + systematic idea hunting, so `stories/` (and eventually
`books/`) run on skill, not just instinct. Research feeds a course; the
course feeds the corpus.

## What

- `_study/short-fiction/` — the subject home: niche scan, teardown
  reports, course curriculum.
- `data` symlink → `/mega/mountain/writings/` — corpora (reference
  stories, educational use only), teardown artifacts, derived catalogs;
  own git repo inside.
- Web recon (done: first pass → `niche-scan.md`); APK teardowns later —
  needs jadx/apktool installed (Manjaro/AUR), targets: Pratilipi,
  Commaful, Galatea, Wattpad.
- Deliverable: `course.md` — module-by-module curriculum with exercises
  landing in `stories/`.
