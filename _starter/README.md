# Starter — what we might do

- `idea_backlog.md` — the capture file. One line per idea, no status, no
  sorting. A sudden idea goes in the moment it arrives.
- An idea that earns evidence graduates to a folder here; rejected lines
  move to the file's `## Decided against` tail.
- Post/story topics also feed the `fb-post`, `story`, and `blog-post`
  skills — they offer backlog candidates when no topic is given.
