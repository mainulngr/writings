# FB campaign home — which account carries the writing?

The question: start a social media writing campaign — use the 2013 profile
(active, cluttered with wrong friends), the 2009 profile (cleaned to zero
posts/friends, meant for a fresh journey), an anonymous Page for
uncomfortable topics, or a separate lane per channel?

## The real problem

Not "which account" — **audience–content fit**. The 2013 clutter hurts
because the wrong audience creates self-censorship. Judge each option by:
does it fix the audience, does it preserve reach, what does it cost.

## The assets

- **2009 profile** — emptied, no friends, no posts. Clean slate, zero reach.
  **Context (Mainul, 2026-10-15):** the emptying was deliberate — a
  follow-only sanctuary after FB fatigue: nobody can reach him, he follows
  profiles he wants. That silence is an asset, not just absence. First
  account — he feels attached to it.
- **2013 profile** — active, cluttered friend list, existing reach.
- **Page (potential)** — anonymous-capable, metrics, scheduling.

## Mechanics that matter

- Personal profiles get the strongest organic reach (friends feed); for a
  small writer, profile reach >> page reach (pages ~1–5% organic unboosted).
- Profiles can be **followed** — Public posts + followers on means the
  friend list isn't the ceiling. With zero friends, comments can be scoped
  shut and messages go to requests: **publish without being reachable** —
  the sanctuary keeps its silence and gains a stage.
- FB ToS: **one personal account per person**. Two profiles is a technical
  violation — enforcement is lax for normal use, nonzero risk that FB flags
  the secondary (2009) account someday.
- Persona pages are the standard BD pattern for anonymous writing.

## Assessment

- **2009 as writing home** — fixes the audience problem completely (every
  friend is a chosen reader), low cost, cold start. Risk: the ToS duplicate
  issue above.
- **2013 as writing home** — needs constant per-post audience filtering
  ("friends except…") or a mass unfriending. High ongoing friction; the
  clutter never truly leaves.
- **Anonymous page** — solves the uncomfortable-topics lane only; useless
  reach for launching the main corpus.

## Working lean (revised 2026-10-15)

- **2009 profile = the writing home — followers-first.** Publish now with
  zero friends; followers ≠ friends, so the sanctuary is preserved while
  the writing gains a channel.
- **Friends are earned, not collected.** Don't cold-request on hope of fit
  (that's how 2013 happened). Convert to friends only people who prove
  they read well — every friend then opted in via the writing itself.
- **Set inbound rules before the first friend** — comment scope, message
  filtering — so the account never recreates the original noise.
- **2013 profile = life/social.** Bridge occasionally; note that
  hard-linking two same-name profiles advertises the duplicate to FB —
  subtle bridging or none is safer.
- **Anon page = third lane, later.** Open when uncomfortable-topic drafts
  accumulate; the corpus can hold those pieces now.
- Fallback if ToS risk bothers: stay on 2013, carve a writing list with
  audience selectors — works, but the friction stays forever.

## Open sub-questions

- Which topics actually need anonymity? (religious questions? social
  critique?) — sizing that lane decides when the page earns its place.
- How visible should the 2013→2009 bridge be, given the duplicate-account
  exposure?
