# Facebook Posting Times – Bangladesh Audience (UTC+6)

_This is a general guideline for Bangladeshi audience, especially for reflective/writing-type posts. Use it as a starting point and adjust based on your own analytics._

## Key assumptions
- Time zone: Bangladesh Standard Time (BST, UTC+6).
- Audience: mostly working-age people + students, active on mobile.
- Content type: thoughtful status, short essays, couplets, not viral memes.

## High-level best windows
- **Morning:** 7:30–9:30 AM
- **Lunch / Midday:** 12:30–2:30 PM
- **Evening (prime):** 7:30–10:30 PM

## How to use this schedule
- Pick **1–2 slots per day** instead of posting in all of them.
- For **heavier, reflective posts** (faith, parenting, deep empathy):
  - Prefer **late evening:** 9:00–10:30 PM.
- For **lighter / hopeful / couplet-style** posts:
  - Try **morning slots** for a "day-starter" feel.
- Keep a simple log in `posts/YYYY_MM_DD.md` noting
  - **Time posted** and **rough reach/engagement**, so you can later adjust this table based on your own data.
